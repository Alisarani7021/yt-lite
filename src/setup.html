نصب یوتیوب لایت روی حساب کلودفلر خودت

هزینه نداره. ورکر روی اکانت خودت ساخته می‌شه و هیچ توکنی به ما داده نمی‌شه.

🔒 امنیت

این سایت هیچ توکن یا رمزی از تو نمی‌خواد. نیازی به کوکی یوتیوب یا گوگل هم نیست؛ هیچ‌وقت کوکی حساب اصلی‌ات رو وارد نکن. نصب با ورود خودت به کلودفلر در همون مرورگر انجام می‌شه.

روش ۱: نصب با یک کلیک (پیشنهادی)
  1. دکمهٔ زیر رو بزن و با حساب کلودفلر خودت وارد شو.
  2. اسم ورکر رو انتخاب کن و تأیید کن؛ KV و بقیهٔ منابع خودکار ساخته می‌شن.
  3. بعد از نصب، آدرس سایتت نشون داده می‌شه.

⚡ Deploy to Cloudflare

روش ۲: با ترمینال خودت (برای کاربرهای فنی)

توکن رو فقط روی کامپیوتر خودت وارد کن، نه جای دیگه:

git clone https://github.com/Alisarani7021/yt-lite
cd yt-lite
export CLOUDFLARE_API_TOKEN=توکن_خودت
npx wrangler kv namespace create YT_CACHE
# id خروجی رو داخل wrangler.toml بذار، بعد:
npx wrangler deploy
اختیاری: کوکی یوتیوب برای ویدیوهایی که باز نمی‌شن

بعضی ویدیوها بدون ورود باز نمی‌شن (پیام «LOGIN_REQUIRED»). اگه این پیام رو دیدی، می‌تونی کوکی یه حساب گوگل دست‌دوم رو به ورکرت بدی.

⚠️ فقط از یه حساب گوگل جدا و بی‌اهمیت استفاده کن. هرگز کوکی حساب اصلی‌ات رو نده؛ کوکی مثل رمز عبوره. امکان داره گوگل اون حساب رو محدود کنه.

  1. با یه حساب گوگل دست‌دوم، روی کامپیوتر (کروم) وارد youtube.com شو.
  2. کلید F12 رو بزن و تب Network (یا «شبکه») رو باز کن.
  3. صفحه رو رفرش کن (F5) و روی یه درخواست که به youtube.com میره کلیک کن.
  4. توی بخش Request Headers (سرصفحه‌های درخواست)، خط cookie: رو پیدا کن و کل مقدارش رو کپی کن.
  5. توی داشبورد کلودفلر ← ورکرت ← Settings ← Variables and Secrets ← Add ← نوع Secret و اسم YT_COOKIE رو بذار و مقدار کپی‌شده رو توش بچسبون. ذخیره کن.
  6. وقتی از حساب دست‌دوم خارج بشی یا کوکی منقضی بشه، دوباره همین مراحل رو تکرار کن.

روش گوشی (اندروید):

  1. Firefox for Android رو نصب کن (کروم افزونه نداره). توی Firefox از منو ← Add-ons ← افزونهٔ Cookie-Editor رو نصب کن.
  2. توی Firefox با حساب دست‌دوم وارد youtube.com شو.
  3. روی صفحهٔ youtube.com، آیکن Cookie-Editor رو بزن و بعد دکمهٔ Copy (کپی) رو بزن. فرمت Header string رو انتخاب کن.
  4. تو همین Firefox، داشبورد کلودفلر رو باز کن و مراحل بالا برای Secret با اسم YT_COOKIE رو انجام بده. با «Paste» همون متن کپی‌شده رو بچسبون و ذخیره کن.
